Latte art

GooeyPainter

Program a Painter to walk around a grid and turn it into pixel art.

It works just like the Neighborhood from Code.org’s CSA course, so your first Java project runs in a real IDE with the same Painter you already know.

Read the docs Get started

Download GooeyPainter.jar and GooeyPainter-sources.jar. Runs on Java 11 or newer.

What’s in the cup

  • Same Painter as Code.org

    Same methods, same messages, same [EXCEPTION] errors. Code from your Code.org lessons runs once you change the import.

  • Made for pixel art

    Paint with hex codes copied straight from pixilart.com, speed the animation up to instant, and label every row and column.

  • Draw your own neighborhood

    Set up the grid in a grid.txt file: . for grass, X for obstacles and B5 for a bucket with 5 paint.

Your first sip

Paint three squares, then step aside so the art shows.

import gooeypainter.*;

public class MyNeighborhood {
    public static void main(String[] args) {
        // Start at (0, 0), facing east, with 10 paint
        Painter artist = new Painter(0, 0, "east", 10);
        artist.paint("red");
        artist.move();
        artist.paint("#FFA500");   // hex codes work too
        artist.move();
        artist.paint("gold");
        artist.hidePainter();
    }
}

Get started in three sips

  1. Grab the jars

    Download GooeyPainter.jar and GooeyPainter-sources.jar.

  2. Drop them in lib

    Put both jars in your project’s lib folder. VS Code shows the docs when you hover over GooeyPainter code.

  3. Import and run

    Add import gooeypainter.*; at the top of your file, write your code and hit Run.
